# 造梦西游4 · 生存大冒险自动答题 bot

基于 OCR + 蒙特卡洛模拟的自动答题程序。读取游戏界面文字，匹配本地题库，用蒙特卡洛前瞻搜索选出最优选项并自动点击，跑完一局冒险自动退出。

> 只做本地操作（截图识别 + 模拟鼠标点击），不修改内存、不篡改协议、不操作网络流量。

## 原理

1. **OCR 识别**：RapidOCR（PP-OCR 模型）识别游戏窗口内的题目、4 个选项、六属性面板、结果文本
2. **题库匹配**：41 道题全部收录（从游戏进程内存只读提取），rapidfuzz 模糊匹配题目与选项
3. **蒙特卡洛决策**（`--mc` 模式）：对 4 个选项各模拟 300~1000 局「抽题 → 随机决策 → 直到冒险结束」，取平均最终积分作为该选项的期望值，选期望最高的选项
   - **survival-first 模拟策略**：后续题目的模拟优先选能成功的选项，全失败时选扣血最少的（比纯随机更贴近真实最优）
   - **分层枚举抽题**：每阶段题目池内不放回枚举组合，消除抽题方差
   - **公共随机数**：4 个选项在同一批题目序列上评估，对比更公平
4. **属性推算**：首轮 OCR 读出六属性初始值，之后按题库奖惩推算账本；结果页用「属性面板数字变化」校验实际成败并校正

## 一局游戏的规则（已实测确认）

- 一局 10 题，分 5 个阶段，每阶段抽题数 `[1, 2, 3, 3, 1]`，池内不放回随机抽
  - 阶段1（10xx 题）1 题 → 阶段2（20xx）2 题 → 阶段3（30xx）3 题 → 阶段4（40xx）3 题 → 阶段5（50xx）1 题
- 每题 4 个选项，各带属性条件（如「运气≥4」）：**条件满足 = 成功**，不满足 = 失败
  - `健康1` = 必成功占位、`健康99` = 必失败占位
- 成功/失败获得不同积分（阶段1-2：+6/+3，阶段3：+9/+4，阶段4：+12/+6，阶段5：+19/+9）并改变六属性
- 六属性：健康/战力/智慧/魅力/运气/灵巧；**健康归 0 立即冒险失败结算**
- 积分每周重置，跨局保留最高分

## 环境要求

- **Windows 10/11**（需要管理员权限运行，见下）
- **Python 3.11**（项目自带 venv，无需手动装）
- **游戏客户端**：造梦西游4（4399 登录器，zmxy_online.exe）
- 屏幕分辨率任意（区域坐标按窗口比例归一化，窗口缩放不失效）

## 安装

```bat
git clone <本项目>
cd survival_bot
venv\Scripts\activate.bat
pip install -r requirements.txt
```

依赖：`rapidocr-onnxruntime`（OCR）、`rapidfuzz`（模糊匹配）、`pillow`/`opencv-python`（图像）、`pywin32`（窗口/鼠标）、`numpy`。

## 使用步骤

### 1. 进入游戏答题界面

打开游戏 → 进入「生存大冒险」→ 开始冒险，看到第一题。

### 2. 框选识别区域（首次使用需要）

```bat
calibrate.bat
```

弹出窗口显示游戏截图，依次拖框圈出 13 个区域（松手即确认，`Esc` 撤销）：

| # | 区域名 | 说明 |
|---|--------|------|
| 1 | `question` | 题目文本区 |
| 2-5 | `opt1`~`opt4` | 四个选项（框略大没关系，点击用 OCR 文本中心） |
| 6-11 | `attr_health/wisdom/charm/luck/smart/power` | 六属性面板数字 |
| 12 | `result` | 结果文本区 |
| 13 | `btn_next` | 结果页「继续」按钮 |

操作：拖拽画框 → 松手确认 → `S` 保存退出。保存于 `data/regions.json`。

> 游戏窗口被其他窗口遮挡时截不到图：按 `R` 可重新截图（自动把游戏切到前台）。

### 3. 运行自动答题

```bat
run_mc.bat                 :: 蒙特卡洛模式（推荐）
run_mc.bat --dry-run       :: 只识别+决策，不点击（验证用）
run.bat                    :: 贪心模式（旧策略，不推荐）
```

- 首次运行会弹 **UAC 管理员授权**——必须点「是」：游戏以管理员运行，bot 必须以同权限才能向游戏窗口注入鼠标点击（Windows UIPI 权限隔离）
- 程序自动找到游戏窗口，开始答题：识别题目 → MC 决策 → 点击选项 → 判定结果 → 点继续 → 下一题
- 每轮控制台输出：题目、选项 OCR、当前属性、各选项期望积分、结果、累计积分
- **跑完一局（10 题）自动检测结算页并退出**
- 随时 `Ctrl+C` 或关闭窗口停止

### 4. 查看日志

运行日志与最终结果在 `log/` 目录：

```
log/console_<时间戳>.log   # 完整运行输出（UTF-8）
log/run_<时间戳>.log       # 最终积分/属性
```

### 5. 离线模拟（可选）

```bat
venv\Scripts\python.exe sim_full.py 100 1000
:: 参数：局数 每选项rollouts。按真实规则完整模拟 7 个角色的得分分布
venv\Scripts\python.exe shadow_price.py 40 500
:: 计算各属性 +1 对期望积分的边际价值（影子价格，分析用）
```

## 注意事项

1. **必须管理员运行**：游戏以管理员权限启动，bot 不提权时点击会被系统拦截（光标不动/点击无效）。UAC 弹窗点「是」。
2. **运行期间请勿操作鼠标**：bot 使用真实鼠标点击（更拟人、Flash 兼容好），期间窗口在前台，鼠标会被占用约 1-2 秒/次。
3. **游戏窗口保持可见**：截图用屏幕捕获，游戏被完全遮挡时截不到画面（会提示等待/重试）。
4. **中途启动**：支持从任意题目开始（自动推断阶段），但建议从第一题开始以获得完整 10 题收益。
5. **账号安全**：程序只读游戏画面 + 模拟鼠标，不碰内存/协议/网络，风险等同于手动操作；点击节奏带随机延迟，无异常行为特征。
6. **网络问题**：首次装依赖建议用国内镜像 `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt`。
7. **框选区域保存后**：窗口位置变化不影响（按比例坐标），分辨率变化一般也不需要重框。

## 免安装版（小白用）

不想装 Python？用打包好的 exe 版本：

- **`survival_bot_小白版.zip`（约 93MB）**：解压即用，内置 Python 运行时 + OCR 模型，无需任何安装
- 结构：`生存大冒险bot.exe`（统一菜单）+ `_internal/`（运行时）+ `data/`（题库）+ `使用说明.txt`（三步教程+常见问题+防封号说明）
- 双击 exe 弹出菜单：`[1] 区域框选` → `[2] 开始答题（MC）` → `[3] 简单模式` → `[q] 退出`
- 首次使用选 `[1]` 框选 13 个区域，之后每次直接选 `[2]` 即可
- 重新打包：`venv\Scripts\pyinstaller --noconfirm survival_bot.spec`

> 杀毒软件可能对 PyInstaller 打包的 exe 误报（无签名），加入信任即可；程序源码全部开源在仓库，可自行编译核对。

## 文件结构

```
survival_bot/
├─ bot.py            # 主程序（真实运行/--dry-run/--mc）
├─ calibrate.py      # 区域框选工具（--test 可验证 OCR）
├─ main.py           # 统一入口菜单（exe 使用）
├─ mc_sim.py         # 蒙特卡洛模拟器（决策核心）
├─ solver.py         # 题库加载/匹配/成败判定
├─ ocr_engine.py     # RapidOCR 封装
├─ sim_full.py       # 离线整局模拟器
├─ shadow_price.py   # 属性影子价格分析工具
├─ status_ui.py      # （已弃用）状态小窗，被控制台输出取代
├─ run_mc.bat / run.bat / calibrate.bat / verify.bat
├─ survival_bot.spec # PyInstaller 打包配置（单 exe）
├─ data/
│  ├─ questions.json      # 41 题完整题库（题目/选项/条件/奖惩）
│  ├─ characters.json     # 7 角色初始属性
│  ├─ regions.json        # 框选区域配置（首次运行生成）
│  └─ shadow_prices.json  # 影子价格表（离线分析生成）
└─ log/               # 运行日志
```

## 数据来源说明

题库（41 题：题目、4 选项、属性条件、成败奖励、结果文本）与抽题规则（阶段池 [1,2,3,3,1]、不放回随机）均通过**游戏进程内存只读 dump + 实测对局校准**获得，非网络抓包、非猜测。其中成败判定语义（属性≥阈值、健康1/99 占位）为推断，经多局实测结果校验一致。
